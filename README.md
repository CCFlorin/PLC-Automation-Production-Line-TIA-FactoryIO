# TIA Portal & Factory I/O Automation Line

A PLC automation project created with **Siemens TIA Portal**, **SIMATIC S7-1500**, **WinCC HMI**, and **Factory I/O**.

The project simulates a small production line. Two stations produce a **Lid** and a **Base**. The parts are checked with vision sensors, moved to an assembly station, packed, placed on pallets, and stored automatically in a warehouse.

## Project Structure

- `FB3` – Lid Production
- `FB2` – Base Production
- `FB4` – Assembly
- `FB7` – Assembly Actuators
- `FB5` – Palletizer
- `FB6` – Warehouse
- `FB8` – Product Counter
- `FC1` – Vision Sensor
- `FC3` – HMI Status
- `FB1` – Reset

## Main Functions

- Automatic Lid and Base production
- Colour detection with vision sensors
- Automatic assembly
- Conveyor and gripper control
- Palletizing
- Automatic warehouse storage
- Product counting
- HMI Start / Stop / Reset
- Display of production and warehouse information
- Alarm message when the warehouse is full

## Software

- Siemens TIA Portal
- SIMATIC S7-1500
- WinCC
- Factory I/O
- PLCSIM
